# GKCOCA - Report

Report on the implementation of the full Coulomb gyrokinetic operator. The
topics that are treated in this manuscript are:

- Context and motivation
- Mathematical background and existing results
- Direct implementation
  - Mathematical accuracy
  - Performance (speed, round-offs)
  - Floating-point precision and compensation methods
- Arbitrary precision implementation
  - Arbitrary precision arithmetics
  - Mathematical simplifications previous developments
  - Performance and accuracy
- Conclusions and further enhancements
